# Смета за 5 минут

Смета или коммерческое предложение, которое считает себя само, сохраняется в PDF и отправляется в мессенджер.
Подходит предпринимателю (КП клиенту) и офисному сотруднику (смета закупки для руководителя).

Без установки и сервера: откройте `index.html` в браузере (двойной клик).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: поля, таблица позиций, итоги, кнопки |
| `style.css` | оформление, версия для телефона, тёмная тема, печать в PDF |
| `app.js` | расчёты, автосохранение, PDF, отправка в WhatsApp / Telegram |

## Функции

1. **Документ**: переключатель «КП клиенту / Смета закупки», номер, дата, от кого и кому.
2. **Позиции**: наименование, количество, единица, цена; сумма строки считается сама. Enter переходит к следующему полю, Enter в последней цене добавляет строку. Удалённую позицию можно вернуть.
3. **Итоги**: скидка %, НДС % (сверху или «цены уже включают НДС»), выбор валюты.
4. **Сохранение**: всё сохраняется в браузере, после обновления страницы данные на месте. «Новый документ» очищает позиции и получателя, ваши данные остаются, номер увеличивается на 1.
5. **PDF**: «Сохранить PDF» открывает окно печати, в нём выберите «Сохранить как PDF». Имя файла подставится само, например `КП №1 ООО Ромашка`.
6. **Отправка**: WhatsApp, Telegram, «Копировать текст», а на телефоне ещё «Поделиться».

## Проверка числами

Нажмите **«Заполнить пример»** (работает и для КП, и для сметы):

| Что проверяем | Должно получиться |
|---|---|
| 20 × 1 500 | 30 000 |
| 2,5 × 2 000 (запятая) | 5 000 |
| Сумма позиций | 40 000 |
| Скидка 10 % | −4 000 |
| НДС 20 % сверху | 7 200 |
| **Итого** | **43 200** |
| Галочка «Цены уже включают НДС» | Итого 36 000, в т.ч. НДС 6 000 |
| В цене написать `abc` | поле красное, сумма строки 0, отправка не пройдёт |
| Скидка 150 | поле красное |
| Обновить страницу | все данные на месте |
